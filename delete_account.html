Suppression de compte

Dernière mise à jour : mai 2026

Veuillez lire attentivement : La suppression de votre compte est irréversible. Toutes vos données seront définitivement effacées.

Comment demander la suppression de votre compte

Pour demander la suppression de votre compte Kartoucha Delivery et de toutes les données associées, veuillez envoyer un e‑mail à l'adresse suivante :

majorofficer4@gmail.com

Informations à fournir

Dans votre e‑mail, veuillez inclure :

  • Votre numéro de téléphone utilisé lors de l'inscription
  • La mention : « Je souhaite supprimer mon compte et toutes les données associées »

Données supprimées

Nous supprimerons les données personnelles suivantes :

  • Numéro de téléphone
  • Nom (le cas échéant)
  • Historique complet des commandes
  • Données de localisation approximative liées aux commandes
  • Toute autre donnée personnelle stockée

Délai de traitement

Les données seront supprimées dans un délai de 7 jours après réception de votre demande. Aucune donnée n'est conservée au‑delà de cette période, sauf obligation légale contraire.
