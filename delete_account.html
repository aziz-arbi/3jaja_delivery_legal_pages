Demande de suppression de compte

Pour demander la suppression de votre compte Kartoucha Delivery, veuillez envoyer un e‑mail à l’adresse suivante : aziz@kartoucha.tn

Dans votre e‑mail, indiquez :

  • Votre numéro de téléphone utilisé pour l’inscription
  • La mention « Je souhaite supprimer mon compte et toutes les données associées »

Nous supprimerons toutes les données personnelles suivantes : numéro de téléphone, nom, historique de commandes, localisation approximative. Les données sont supprimées dans un délai de 7 jours après réception de votre demande.

Aucune donnée n’est conservée au‑delà de cette période, sauf obligation légale.
